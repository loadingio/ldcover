# 加入可自訂的 Dialog helper（alert / confirm / prompt / dialog）

## 目標

在 ldcover 上加一層 **promise 版對話框 helper**，讓宿主程式能用一行呼叫取代瀏覽器原生
`alert()` / `confirm()` / `prompt()`（那些會被 headless / 自動化擋住、也無法套用站台樣式）。

核心 overlay/promise 機制沿用現有 ldcover（`get()` → Promise、`set(v)` / `data-ldcv-set`
解析、escape/scroll/z-index）。**這個 task 只補「對話框內容層」**，不重造 cover。

> 需求來源：otl/design（Tailwind 站台）有 38 個 `alert`、13 個 `confirm`、1 個 `prompt`
> 要換成站內 dialog。其它 loading.io 專案也會用到，故做進 ldcover 共用。

## 設計原則（重要）

1. **樣式無關 / 可主題化**：只輸出語意結構 + class hook，**不綁 bootstrap 外觀**。
   宿主（Tailwind / 自家 CSS）要能只靠 class 或 `classes` 選項重新著色。ldcover 只附**最小結構樣式**。
2. **內容可完全自訂**：訊息可傳純文字、HTML 字串、或 DOM node（逃生艙，複雜內容自己塞）。
3. **promise-based**：回傳被點按鈕的 `value`；含輸入框時一併回欄位值。
4. **可累積 / 巢狀**：沿用 ldcover 的 autoZ，多個 dialog 疊加要正確。

## API

### 便利方法（原生替代，drop-in）

```js
ldcover.alert(message, opts?)    // → Promise<void>（按確定後 resolve）
ldcover.confirm(message, opts?)  // → Promise<boolean>（確定=true、取消/escape=false）
ldcover.prompt(message, opts?)   // → Promise<string|null>（確定回字串、取消回 null）
```

共同 `opts`（皆選配）：`title`、`okText`（預設「確定」）、`cancelText`（預設「取消」）、
`danger`（確定鈕用 danger variant）、`size`（'sm'|'md'|'lg'）、`classes`（加在 `.ldcv` 上的額外 class）。
`prompt` 另有：`placeholder`、`value`（預設值）、`type`（input type，預設 'text'）、`required`。

### 泛用方法

```js
ldcover.dialog({
  title,                       // 選配標題
  content,                     // string（純文字，會 escape）｜ DOM node
  html,                        // 或 raw HTML 字串（與 content 二擇一；不 escape）
  fields,                      // 選配輸入欄位：[{ name, label?, type='text', placeholder?, value?, required? }]
  buttons,                     // [{ label, value, variant?, autofocus? }]  variant: 'default'|'primary'|'danger'
  escape = true,               // esc / 點背景 → 以 cancelValue resolve
  cancelValue = null,          // 被 escape/背景關閉時的回傳值
  size,                        // 'sm'|'md'|'lg'
  classes,                     // .ldcv 額外 class（主題化 hook）
}) // → Promise<{ value, fields }>   value = 被點按鈕的 value；fields = { [name]: 輸入值 }
```

便利方法只是 `dialog()` 的預設組合：
- `alert` → 單一 primary 按鈕（value 隨意），resolve void。
- `confirm` → `[{label:cancelText,value:false},{label:okText,value:true,variant:danger?'danger':'primary',autofocus:true}]`，回 `value === true`。
- `prompt` → `fields:[{name:'value',type,placeholder,value,required}]` + cancel/ok 按鈕；ok 回 `fields.value`、cancel 回 `null`。

## 行為細節

- **焦點**：開啟後 focus 到 `autofocus` 按鈕；有 fields 時 focus 第一個欄位。
- **Enter**：在 prompt/單行輸入按 Enter＝觸發 primary/autofocus 按鈕（送出）。
- **Escape / 點背景**：`escape:true` 時以 `cancelValue` resolve（confirm→false、prompt→null）。沿用 ldcover `escape` 與背景點擊關閉。
- **required 驗證**：欄位 `required` 未填時，送出鈕不 resolve，於欄位下方顯示錯誤訊息（結構 + class，不硬套顏色）。
- **實作建議**：lazy 建一個 resident、隱藏的共用 ldcover 實例；每次呼叫重建 `.inner` 內容、用現有
  `data-ldcv-set` 綁按鈕 value、`get()` 等待、`set()` resolve；escape/背景走 `cancel()` 但轉成
  resolve(cancelValue)（不要 reject，宿主端才不用每個都 try/catch）。多實例累積時各自獨立。

## 結構與 class hook（範例，實作可微調）

```
.ldcv.ldcv-dialog
  .base .inner
    .ldcv-dialog__title      (title，可省略)
    .ldcv-dialog__body       (content / html / node)
    .ldcv-dialog__fields     (每欄 .ldcv-dialog__field > label + input + .ldcv-dialog__error)
    .ldcv-dialog__actions    (button.ldcv-dialog__btn[data-ldcv-set] + variant class:
                              --default / --primary / --danger)
```

`src/ldcv.styl` 只加**結構性**樣式（間距、排列、按鈕基本 reset）；顏色/圓角等留給宿主用上述 class 或 `classes` 覆寫。

## 驗收標準

1. `await ldcover.alert('hi')`、`await ldcover.confirm('ok?')`（true/false）、
   `await ldcover.prompt('name?')`（字串 / null）皆如規格運作。
2. `ldcover.dialog({...})` 支援：自訂 html/node 內容、多顆按鈕（回各自 value）、多個輸入欄位（回 fields）、
   danger variant、required 驗證、escape/背景以 cancelValue 關閉。
3. **樣式無關**：不載入 bootstrap 也能正常顯示（結構正確），外觀可用 class 覆寫；預設不強加品牌色。
4. 多個 dialog 疊加 z-index 正確。
5. `dist/` 已重建；README/CHANGELOG/version 已更新；demo 頁可手動操作驗證。
